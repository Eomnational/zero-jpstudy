# ZERO 日语联想词书

依据用户提供的 N5 截图词书网页提取 894 个词条，并补充「社会人」作为联想桥梁。每个词条展示日语词形、读音、中文意思和分类。汉字联想页完整覆盖原词表 259 个汉字联想词和补充的「社会人」，共 260 词。优先按连续两个以上汉字的共同词段分组；「社会人 → 社会 → 会社」是人工联想链。剩余词按「同字线索」或「独立记忆」展示；同字线索不表示读音或词义相同。

## 运行

需要 Python 3.10+ 和 Node.js 18+。分别开启两个终端：

```bash
python3 backend/server.py
```

```bash
cd frontend
npm install
npm run dev
```

访问 http://127.0.0.1:5173 。学习进度保存在 `backend/progress.sqlite3`。前端包含汉字词族、分类词表、翻卡、听音默写和每日计划。每日计划可设置新词与复习额度，练习结果写入 SQLite，复盘页展示近 14 天新词、复习量和正确率，并可导出当天已完成词的 UTF-8 CSV（Excel 可直接打开）。CSV 包含词形、读音、罗马音、意思、分类以及当天练习记录。朗读使用浏览器或系统的日语语音。

## 数据说明

`backend/words.json` 来自提供的 HTML 中内嵌词表。原页面标记的截图来源保存在每条数据的 `source` 字段。`社会人` 标为「联想补充」，不计入原 894 词。分类沿用原词表。含训读成分的「大勢、家賃、毎年、毎月」保留在汉字联想页，并标明混合读法，避免把它们当作纯音读词。
